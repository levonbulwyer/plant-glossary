# Plant Biology Glossary

A study tool for tracking plant biology terms. Built with React + Vite.

## Features
- Search terms and quiz questions instantly
- Filter by status: To Do, Learning, Learned
- Click the dot on any card to cycle its status
- Expand a card to see the quiz question and set status manually
- Add your own terms
- Progress saved automatically in your browser

## Deploy (Netlify — no code needed)

1. Download this folder as a zip
2. Go to [netlify.com](https://netlify.com) and log in
3. Drag the zip onto the Netlify dashboard
4. Done — you'll get a live URL

## Local development (optional)

```bash
npm install
npm run dev
```

Then open http://localhost:5173

To build for production:
```bash
npm run build
```
